# ✨ Data Analysis Projects: Job Analysis 

## Summary

This repository contains two projects completed in Excel: a dashboard and an analysis. These projects were done to help job seekers around the world better understand how much tech jobs pay. The dataset was obtained in Kaggle [https://www.kaggle.com/datasets/yaaryiitturan/global-tech-salary-dataset].

Each project has its own README, so feel free to check it before opening the respective files.
